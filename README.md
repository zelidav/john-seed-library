# John Seed Library

Consolidated strain-genetics reference compiled from the handwritten inventory cards and 42 pack photos of the library.

## Live site

[View the library →](https://zelidav.github.io/john-seed-library/)

## What's in this repo

- `index.html` · `styles.css` · `app.js` — static site
- `strains.json` — consolidated data (38 strains across Sealed / Open / Other / Bonus)
- `img/` — full-resolution pack photos (`IMG_4484.jpg` – `IMG_4525.jpg`)
- `thumb/` — 800px thumbnails

## Source

- `Strain_Genetics_Reference.docx` (April 2026 compilation)
- 42 HEIC photos of pack labels and handwritten index cards, converted to JPEG

## Sections

- **Sealed** — unopened packs (Covert, Tiki Madman, Cult Classics, Ethos, A&B Company, etc.)
- **Open** — opened/in-use packs (Bloom, Mephisto, Envy, Cult Classics, Exotic Genetix, Crane City)
- **Other** — misc craft/testers (Geist, Ethos, Envy, Savage, Fire Farms, GRF, Humble Jungle)
- **Bonus** — strains found in photos not on the master inventory cards (Phantom Fire, Sin City, Gene Traders, Lyme Rising, Geo Farms, Kali's, Dinosaur Biscuits)

## Features

- Full-text search across strain, breeder, genetics, lineage, phenotype, profile, and notes
- Filter by section, phenotype (Indica/Sativa/Hybrid), and lineage family (Runtz, OGKB, Cookies, Zkittlez, Gelato, OG Kush, Chem/Diesel, Sherbet, GMO/Garlic, etc. — 32 tags total)
- Per-strain breeder link (site or IG) and seedfinder.eu lookup
- Per-pack and total estimated retail valuation (mid-market craft-seed ranges)
- Live subtotal updates as filters change
